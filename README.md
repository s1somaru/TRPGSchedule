# たくよせ

TRPG の卓の日程を、ログインなしで「寄せる」ための Web アプリです。

- サービス:https://takuyose.s1somaru.workers.dev
- 仕様書:[docs/specification.md](docs/specification.md)(機能・データの扱い・セキュリティ・API・データモデル)

**予定は1回入れるだけ。参加している卓ぜんぶに反映されます。**

一般的な日程調整サービスは、卓(調整ページ)ごとに予定を入れ直す必要があります。このアプリでは、プレイヤーが自分の予定表(カレンダー)を1つ持ち、GM が作る卓のページがそれを参照します。複数の卓に参加していても、予定の入力は1回で済みます。

## 特徴

- **ログイン不要**:アカウント登録やパスワードはありません
- **1つの予定表を使い回せる**:今日から6か月先まで、日ごとに ◯ / △ / × とひとことメモを入れられます
- **時間帯まで判定**:必要な日だけ「空いている時間」を入れておくと、卓の時間帯(21:00〜 など)と照らして、参加できるかを自動で判定します。曜日ごとの「いつもの時間」も決めておけます
- **まとめて入力**:日付を長押ししてなぞると、まとめて付けられます。記号・時間・メモを「スタンプ」にして、いくつもの日に付けることもできます
- **卓ページで一目でわかる**:候補日ごとに全員の予定と人数が並び、GM 全員が参加できる日や、全員が ◯ の日がすぐわかります。日本の祝日も色で表示します
- **開催日を決める**:GM が開催日を決めると、卓ページの一番上に表示されます。キャンペーンなど、開催日は何日でも決められます
- **共同GM**:GM を複数人にできます。GM の1人が URL をなくしても、卓を管理し続けられます
- **他の日の予定は見せない**:卓ページに出るのは、その卓の候補日の予定だけです
- **終わった卓は記録として残る**:開催日と参加者の名前を、思い出として残します
- **URLを貼るとタイトルが出る**:卓URLを Discord などに貼ると、「たくよせ(卓のタイトル)」のカードが出ます

## 使い方

1. トップページで **「カレンダーを作る」**。表示名を入れると、あなた専用の **編集URL** ができます
2. 編集URLを、メモアプリやブックマークなど自分だけが見られる場所に保存します
3. カレンダーで、日ごとに ◯ / △ / × を付けます(必要なら空いている時間やメモも)
4. GM は **「卓を作る」** で候補日を選び、できた **卓URL** をプレイヤーに送ります
5. プレイヤーは卓URLを開いて **「この卓に参加する」**。あとは自分のカレンダーを更新するだけで、卓ページに反映されます

## 大事な注意:編集URLはパスワードと同じです

このアプリにはログインがない代わりに、**編集URLを知っていること** が本人である証明になります。

- 編集URLを他人に教えると、その人はあなたの予定を書き換えられます
- 卓に誘うときは、卓ページの **「卓URLをコピー」** を使ってください(卓URLは見るためのURLで、編集はできません)
- 編集URLをなくすと、取り戻す方法はありません。人に知られたかもしれないときは、カレンダーのメニューから **「URLを作り直す」** を使ってください(古いURLはすぐ使えなくなります)
- 卓URLは、知っている人なら誰でも見られます。卓に出るのは、参加者の表示名と候補日の予定だけです(GM は候補日を変えられるので、候補日にした日の予定は見られます)

### データの保存期間

- 1年間使われていないカレンダーは削除されます(参加していた卓には名前だけが残ります)
- 過去の予定は90日分だけ残します
- 最後の開催日(決まっていなければ最後の候補日)から90日たった卓は、予定を除いた「記録」に切り替わります

## 仕組み

| 役割 | 使っているもの |
|---|---|
| サーバー | Cloudflare Workers + [Hono](https://hono.dev/) |
| データ | Cloudflare D1(SQLite) |
| 画面 | [Preact](https://preactjs.com/) + [Vite](https://vite.dev/)(TypeScript) |
| 入力チェック | [Valibot](https://valibot.dev/)(サーバーと画面で共通) |
| テスト | Vitest + `@cloudflare/vitest-plugin` |

- 編集URLの秘密は、URL の `#` より後ろに入れています。`#` より後ろはサーバーに送られないため、アクセスの記録に残りません。API には `Authorization` ヘッダで送ります
- データベースには、秘密そのものではなくハッシュ値(SHA-256)だけを保存しています
- 画面と API の両方に、Content-Security-Policy などのセキュリティヘッダを付けています。外部のスクリプト(アクセス解析・広告など)は読み込みません
- 詳しくは [仕様書](docs/specification.md) の「データの扱いとプライバシー」「セキュリティ」を見てください

## 開発

Node.js 22 以上が必要です。

```bash
npm install
npm run dev                # 画面をビルドし、手元用のデータベースにテーブルを用意して、サーバーを起動する(http://localhost:8787)
```

```bash
npm test                   # テスト(Workers と同じ環境で動きます)
npm run typecheck          # 型チェック
```

### フォルダ構成

```
docs/            仕様書
migrations/      データベースのテーブル定義
public/          画面と一緒に配信するファイル(セキュリティヘッダの設定・アイコン・URLのカード画像)
src/server/      API(Hono)、卓ページのカード、毎日の定期処理
src/client/      画面(Preact)
src/shared/      サーバーと画面で共通の部品(入力チェック・日付と時刻の計算・祝日・開催判定)
test/            テスト
```

### デプロイ

```bash
npx wrangler login
npx wrangler d1 create takuyose --location apac   # 表示された database_id を wrangler.jsonc に書く
npm run db:migrate:remote
npm run deploy
```

`wrangler.jsonc` の `"workers_dev"` が公開のスイッチです。`true` で `https://takuyose.s1somaru.workers.dev` から開けます。`false` にして `npm run deploy` し直すと、Cloudflare に置いたまま外からは開けなくなります。

### 運営するときの注意

- `npx wrangler tail` でリアルタイムのログを見ると、リクエストのヘッダ(編集URLの秘密を含む)が表示されます。出力を人に見せたり、貼り付けたりしないでください
- `npm run feedback` は返信先(個人情報)も表示します。画面共有中などに実行しないでください

### お問い合わせ・評価を読む

アプリの「お問い合わせ」と、フッタの評価で送られた内容は、データベースの `feedback` 表に保存されます。内容と評価は残し、返信先(個人情報)だけを1年で自動で消します。

お問い合わせが届くと、運営者に [Resend](https://resend.com) でメールが届きます(内容と返信先はメールに入れません)。使うには、Worker の secret に Resend の API キーと宛先を入れます。入れなければ通知はしません。

```bash
npx wrangler secret put RESEND_API_KEY   # 送信だけできるキー
npx wrangler secret put NOTIFY_EMAIL     # 知らせる先(Resend のアカウントのアドレス)
```

```bash
npm run feedback          # 本番(新しい順に50件)
npm run feedback:local    # 手元の開発環境
npm run feedback:export   # 本番の控えを backups/feedback.json に保存(返信先は入れません。GitHub には上がりません)
```
